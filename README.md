# 陈晋钦 · 个人主页

一个纯静态的响应式个人简历网站，采用深色编辑风设计（ink + 香槟金），部署在 GitHub Pages 上。

## 目录结构
```
resume-site/
├── index.html        # 首页
├── about.html        # 关于我（教育、技能、荣誉）
├── projects.html     # 科研项目（5 个项目的详细工作/结果 + PPT 流程图与图表）
├── awards.html       # 竞赛荣誉
├── experience.html   # 实践经历
├── statement.html    # 自述与推荐（个人陈述/推荐信/自荐信）
├── contact.html      # 联系我
├── css/style.css     # 设计系统与样式
├── js/main.js        # 交互（含图片灯箱）
├── assets/
│   ├── img/          # 图片素材（人像、证书、项目图、活动照）
│   └── resume.pdf    # 简历 PDF（未在前台提供下载）
└── .nojekyll
```

## 内容来源
内容整合自 8 份简历文件 + 5 份保研材料（自荐信、个人陈述、推荐信×2、简历专硕），图片取自「深大红色.pptx」，人像已抠去白底以适配深色主题。

- 个人陈述已精简为**纯自述**（移除了申请保研/预推免相关表述）；自荐信段落仍保留其原有申请语体。
- 首页人像为**纯照片**，无任何数值标注/文字叠加。
- 科研项目页根据 PPT 详细内容重写：每个项目含背景/方案/核心贡献/结果，配流程图、柱状图、性能表、论文海报等（详见 assets/img/ 的 wm-*、rag-*、qiaopi-* 图片）。

## 图片说明
- `assets/img/portrait.png`：个人肖像（已去背景）
- `cert-*.jpg`：获奖证书；`proj-*.jpg`：项目架构/论文海报；`exp-*.jpg`：实践与活动照片
- 所有画廊图片支持点击放大（灯箱）

## 部署到 GitHub Pages
推送到 `c11c111.github.io` 仓库的 `main` 分支即可，Pages 会自动重新构建。

## 自定义修改
- 配色：`css/style.css` 顶部的 `:root` CSS 变量。
- 联系方式：搜索 `17833952955` 或 `陈晋钦` 批量替换。
- 更换照片：替换 `assets/img/` 下同名文件即可；证书/活动照图片名见上表。
- 注：已按需求移除前台所有「下载简历」入口。
